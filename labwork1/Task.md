# Лабораторная работа 1: WordCount

Условие и решение · C++

### Условие

Нужно написать консольную программу WordCount, которая для каждого переданного файла считает строки, слова, буквы/цифры и байты.

Формат запуска: `WordCount [OPTION]... [FILE]...`

Для каждого файла выводится одна строка: `<lines> <words> <alnum> <bytes> <filename>`

### Опции

* `-l`, `--lines` — количество строк
* `-w`, `--words` — количество слов
* `-a`, `--alnum` — количество букв и цифр
* `-c`, `--bytes` — размер файла в байтах
* Короткие опции можно склеивать: `-lawc`.
* Опции могут стоять после имён файлов: `file1 file2 -lw --bytes`.
* Без опций выводятся `lines words bytes filename`.
* Колонки всегда выводятся в порядке lines, words, alnum, bytes, как бы ни шли опции.
* Имя файла печатается ровно так, как его передали. Разделитель — один пробел, в конце строки `\n`. Строку «total» не выводить.

### Правила подсчёта

* **Строки**: считаются символы `\n`. Если файл не пустой и последний байт не `\n`, добавляется ещё одна строка. Пустой файл — 0 строк.
* **Слова**: слово — непрерывная последовательность непробельных байтов. Пробельные символы: пробел, `\t \n \r \v \f`. Байт `\0` пробелом не считается.
* **alnum**: только `A-Z`, `a-z`, `0-9`.
* **bytes**: количество прочитанных байтов (`\r\n` — это 2 байта). Файл читается в бинарном режиме.
* Размер файла не ограничен, поэтому целиком в память его не читать, а читать кусками (буфером).

### Ограничения

* Нельзя использовать `std::string`, `std::string_view`, контейнеры (`vector`, `map` и т.п.), `std::regex` и сторонние библиотеки. Работа идёт с `char*`, массивами и `<cstring>`.
* Codestyle: функции и структуры — CamelCase, переменные и поля — lower_case, константы — kCamelCase.
* CI собирает код через через `clang++` с санитайзерами `-fsanitize=address,undefined` и прогоняет тесты при Pull Request в main.
