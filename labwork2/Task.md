# Лабораторная работа 2: int2026_t

Условие · C++

### Условие

Нужно реализовать свой тип `int2026_t` — целое число со знаком размером 2026 бит. Диапазон значений: от $-2^{2025}$ до $2^{2025} - 1$ (примерно 610 десятичных цифр).

Код пишется в `lib/number.h` (что хранится внутри числа) и `lib/number.cpp` (как работают операции). Новые файлы добавлять и менять структуру проекта нельзя.

### Что нужно реализовать

| Функция | Что делает |
| :--- | :--- |
| `from_int(int32_t)` | создаёт число из обычного `int` (включая `-2147483648`) |
| `from_string(const char*)` | создаёт число из строки вида `[+-]?[0-9]+`; ведущие нули допустимы, `-0 == 0` |
| `+ - * /` | арифметика; деление округляет к нулю: `-7 / 3 == -2` |
| `== !=` | сравнение |
| `<<` | вывод в поток; возвращает тот же поток, чтобы работало `cout << a << " " << b` |

### Переполнение

Переполнение — не неопределённое поведение, а «по кругу»: всё считается по модулю $2^{2026}$.

* `MAX + 1 == MIN`, `MIN - 1 == MAX`
* `MIN * 2 == 0`
* `MIN / -1 == MIN`
* Строка с числом больше MAX тоже «заворачивается».

Деление на ноль и некорректные строки тесты не проверяют.

### Ограничения

* Нельзя использовать `std::string`, `std::vector` и другие контейнеры, а также `std::bitset`.
* `sizeof(int2026_t) <= 254` байта (проверяется через `static_assert`).
* Неиспользуемые биты не расширяют диапазон: в 254 байтах 2032 бита, но значащих только 2026.
* Codestyle: свои функции — CamelCase, переменные и поля — lower_case, константы — kCamelCase; имена `from_int`, `from_string`, `int2026_t` заданы заданием.
* CI собирает код через `clang++` с санитайзерами `-fsanitize=address,undefined` и прогоняет тесты при Pull Request в main.
